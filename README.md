## Install


```bash
# GUI (PySide6 — recommended, LGPL)
pip install "ukm[pyside6]"

# GUI (PyQt6 — alternative, GPL)
pip install "ukm[pyqt6]"

# CLI only (no Qt required)
pip install ukm
```

To force a specific Qt binding at runtime:

```bash
UKM_QT=PyQt6 ukm-gui
```
